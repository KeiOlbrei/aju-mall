# Toormaterjal

Siia käib **toores materjal, mida AI-teenuse pakkuja tohib töödelda**: ChatGPT eksport, häälmärkme transkript, ekraanipilt, PDF, vana pakkumine või Wordi fail.

See kaust on `.gitignore`-is, seega tema sisu GitHubi ei lähe. See kaitseb GitHubi ajalugu — **mitte AI-töötluse eest**. Kui palud Claude'il faili lugeda, töötleb AI-pakkuja selle sisu.

> **Kaks küsimust:** kas see tohib GitHubi ajalukku jääda? Kas AI-pakkuja tohib seda töödelda?

Kui teise vastus on “ei”, ära pane faili siia AI jaoks lugemiseks. Hoia seda offline ja anonümiseeri esmalt tööriistaga, mis ei saada sisu AI-le ega internetti.

## Kuidas kasutada

> *Loe `toormaterjal/` läbi ja destilleeri see mu ajju. Toorikut ennast jälgitavasse Braini kausta ära kopeeri.*

Kui materjal on teises kaustas ja AI tohib seda töödelda, ei ole vaja seda siia kopeerida. Ava või näita ainult konkreetset vajalikku kausta või faili — mitte kogu `Dokumendid` kausta.

See kaust on nende lubatud toorikute jaoks, millel ei ole mujal kodu.

## Miks see fail siin on

Git ei salvesta tühje kaustu. Ilma selle failita kaoks tühi `toormaterjal/` pärast repo loomist.

Seda faili võid muuta või märkmetega täiendada. Kustuta ainult siis, kui sa seda kausta enam ei kasuta.
